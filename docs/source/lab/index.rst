NewWorldTrading
===================

**NewWorldTrading** is an interactive platform for exploring LLM-powered trading agents: backtesting on historical Alpaca data, paper trading, and comparison against buy-and-hold and index baselines.

- **Live app:** `localhost:8000 <https://localhost:8000/>`_
- **Community:** `Discord <https://discord.gg/xyC3MQAWNj>`_

Start with :doc:`overview`, or use the **NewWorldTrading** section in the sidebar.
