      Making a strategy exportable
      
            
      
                
      
                    Every strategy here -- and every strategy the Testing page accepts -- is one plain Python function,
                    run in an isolated sandbox with no file, network, or system access:
                
      
                
      def decide(price_history):
    # price_history: {"AAPL": [{"t": "2026-08-01", "close": 100.0}, ...], ...}
    # -- one list of {date, close} entries per symbol, oldest first, up to and
    # including the most recent close. Only math, statistics, json, and
    # datetime may be imported; no eval/exec/open/os/subprocess/network/etc.
    weights = {}
    for symbol, points in price_history.items():
        if len(points) >= 2 and points[-1]["close"] > points[0]["close"]:
            weights[symbol] = 1.0
    return weights  # {"AAPL": 0.5, ...} -- target weight (0-1) per symbol
      
                
      
                    If you wrote a strategy outside this bot -- as a plain .py file with just that function
                    in it -- you can upload it as-is, either here (the "Upload a strategy" box above) or on the
                    Testing page, where it will be scanned for
                    safety and checked that it's actually a strategy before being backtested over the most recent completed
                    year with a $1,000 wallet.
                
      
                
      
                    To make it a re-shareable file with its name and description attached (what this page's own
                    Export button produces), package it as a single JSON file shaped like this:
                
      
                
      {
  "format": "agentic-trading-lab-strategy-v1",
  "name": "My Strategy",
  "description": "What it does, in a sentence or two.",
  "code": "def decide(price_history):\n    ...",
  "source": "external"
}
      
                
      
                    Save that as my_strategy.strategy.json and upload it the same way as a .py file --
                    both this page's upload box and the Testing page accept either. Only name and code
                    are required; description and source are optional and default to blank/"external".
